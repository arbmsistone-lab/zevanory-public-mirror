Como mandar orçamento pelo WhatsApp

O que um orçamento precisa ter para ser entendido de primeira, um modelo para copiar e adaptar e como acompanhar depois do envio.

O que todo orçamento precisa ter

  1. Nome do cliente e data.
  2. O que está incluído, em itens curtos (e o que não está, se houver dúvida comum).
  3. Valor de cada item e valor total.
  4. Prazo de entrega ou execução.
  5. Formas de pagamento e condições (entrada, parcelamento).
  6. Validade do orçamento.
  7. Próximo passo claro: como o cliente confirma.

Modelo para adaptar

Orçamento – [seu negócio]

Cliente: [nome] · Data: [data]

Itens: 1) [item] – R$ [valor] · 2) [item] – R$ [valor]

Total: R$ [total]

Prazo: [prazo] após a confirmação

Pagamento: Pix, cartão ou [outra forma]. [Condição de entrada/parcelamento, se houver]

Validade: até [data]

Para confirmar, é só responder “confirmo” que eu reservo a data para você.

Dicas de envio

  1. Mande o orçamento em uma única mensagem organizada (ou em PDF, se for longo) em vez de vários textos soltos.
  2. Antes do valor, confirme em uma linha o que a pessoa pediu: isso evita mal-entendidos.
  3. Se houver opções, apresente no máximo duas ou três.
  4. Evite áudio para o valor final: texto fica registrado para os dois lados.

Depois do envio

Combine quando vai retomar: “Posso te chamar amanhã à tarde para saber o que achou?”. Se não houver resposta, use uma retomada curta e educada. Veja modelos em mensagem para cliente que sumiu.

Para calcular o preço com margem antes de mandar o orçamento, use a calculadora de preço de venda.

Perguntas

Dúvidas comuns

Orçamento pelo WhatsApp tem validade?

Tem o valor que você combinar. Por isso, informe sempre a validade e as condições por escrito na própria mensagem.

Devo mandar o orçamento em PDF?

Para orçamentos com muitos itens, PDF fica mais organizado. Para orçamentos simples, uma mensagem bem estruturada costuma bastar.

E se o cliente pedir desconto?

Antes de reduzir o preço, considere ajustar o escopo, o prazo ou a forma de pagamento. Use a calculadora para ver até onde a margem permite.
