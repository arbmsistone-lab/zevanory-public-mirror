# EG-0049 — Profundidade orgânica ARBM SIST

Status: APROVADO COM RESTRIÇÕES
Data: 2026-08-31
Escopo: ampliar utilidade da página pública /arbm-sist sem criar doorway pages, sem alterar identidade pública protegida e sem liberar venda.

## Evidências independentes
1. Google Search Central — Search Essentials: conteúdo útil, confiável, people-first; usar termos que as pessoas usam; links rastreáveis.
   https://developers.google.com/search/docs/essentials
2. Google Search Central — Creating helpful, reliable, people-first content: conteúdo deve trazer valor original, profundidade, autoria/contexto e evitar produção feita primariamente para manipular ranking.
   https://developers.google.com/search/docs/fundamentals/creating-helpful-content
3. OpenAI — Codex: posicionamento atual inclui trabalho de engenharia ponta a ponta, worktrees, ambientes cloud e fluxos multiagente.
   https://openai.com/pt-BR/codex/
4. Anthropic — Claude Code on the web: execução remota em repositórios GitHub, tarefas assíncronas e criação de pull request para revisão.
   https://support.claude.com/pt/articles/12618689-claude-code-na-web

## Decisão
Aprovar expansão editorial dentro da própria /arbm-sist com conteúdo comparativo orientado a decisão, linguagem factual e diferenciação por arquitetura/processo — não por promessa de superioridade.

## Restrições
- Não declarar ARBM SIST como “melhor”, “nº 1” ou vencedor universal.
- Não inventar benchmark, clientes, avaliações, economia, precisão ou produtividade.
- Não criar massa de páginas para palavras-chave nesta etapa.
- Não alterar SALE_GLOBALLY_ENABLED, PRE_SALE_GATES_APPROVED, checkout, WhatsApp comercial ou mídia paga.
- ZEVANORY permanece marca-mãe; ARBM SIST permanece produto.
- Não tocar em public/index.html ou vercel.json nesta frente isolada.
