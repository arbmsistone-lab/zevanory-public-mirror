# Assets sociais oficiais ZEVANORY

Variantes derivadas exclusivamente da identidade oficial, sem alterar a geometria do monograma.

- `zevanory-social-profile-1080.svg`: avatar quadrado, 1080x1080, fundo `#05070A`.
- `zevanory-facebook-cover-1640x624.svg`: capa institucional, 1640x624, fundo `#05070A`.
- PNGs de entrega ficam em `public/brand/social/`.

Uso:
- Perfil Facebook e Instagram: `zevanory-social-profile-1080.png`.
- Capa Facebook: `zevanory-facebook-cover-1640x624.png`.

Regra: não esticar, rotacionar, recolorir ou substituir o monograma oficial.
